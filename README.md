# AR Scenery

An AR scenery experience using marker tracking and three.js integration for realistic scenes.

A **WhiteHat Jr** project built with A-Frame — a WebXR framework that renders 3D and Augmented Reality scenes directly in the browser.

## What I Did
- Built a 3D scene with A-Frame entities, primitives, and components
- Added materials, textures, lighting, and camera controls
- Implemented AR marker-based tracking (AR.js) where applicable
- Added animations and interactivity to the scene

## How to Run
Open `index.html` in a browser that supports WebXR, or serve locally:

```bash
python3 -m http.server 8000
```

## Tech Stack
- HTML / JavaScript
- A-Frame (WebXR)
- AR.js (for marker-based AR projects)
